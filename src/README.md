# 📊 Reconocimiento de Dígitos Manuscritos

Proyecto de Machine Learning para clasificar dígitos escritos a mano usando redes neuronales convolucionales (CNN) y comparación con KNN y SVM.

---

## 🚀 Tecnologías
- Python
- TensorFlow / Keras
- Scikit-learn
- Matplotlib

---

## 🧠 Modelos utilizados
- CNN (principal)
- KNN
- SVM

---

## 📂 Dataset
- MNIST (70,000 imágenes de dígitos manuscritos)

---

## 📈 Métricas
- Accuracy
- Precision
- Recall
- F1-score
- Matriz de confusión

---
